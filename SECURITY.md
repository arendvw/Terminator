# Security Policy

## Supported versions

Only the latest release of the `Terminator` and `Terminator.Templates` packages on
[NuGet](https://www.nuget.org/packages/Terminator) receives security fixes. Please upgrade
before reporting an issue.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/arendvw/Terminator/security/advisories/new).

Please include:

- the affected package and version,
- a description of the issue and its impact,
- steps or a minimal project to reproduce it.

This is a small, maintainer-run project, so responses are best effort. We aim to acknowledge
reports within 7 days and will keep you updated as we investigate. Once a fix is released we
publish a GitHub security advisory and credit the reporter, unless you prefer to stay anonymous.

## Scope

Terminator runs external processes (via CliWrap) and its helpers handle credentials such as
NuGet and npm API keys and GitHub tokens. Examples of in-scope issues:

- command or argument injection through Terminator's helpers,
- credentials being logged, written to disk, or leaked to child processes unexpectedly,
- vulnerable dependencies shipped in the `Terminator` package or generated by the templates.

Issues in upstream dependencies (CommandDotNet, Spectre.Console, CliWrap, NuGet client
libraries) should be reported to those projects; we will pick up fixed versions through
Dependabot.
